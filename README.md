# # 🐍 Сравнительный анализ Backend-фреймворков Python

> Одностраничный аналитический сайт о сравнении Django, Flask и FastAPI по основным характеристикам и сценариям применения.

---

## 📌 О проекте

Данный проект выполнен в рамках задания «Сравнительный анализ Backend-фреймворков Python».

Цель проекта — исследовать популярные Python-фреймворки для разработки серверной части веб-приложений и определить, какой инструмент наиболее целесообразно использовать в зависимости от требований проекта.

На сайте представлены:

* сравнительный анализ Django, Flask и FastAPI;
* особенности архитектуры каждого фреймворка;
* сравнение скорости разработки и производительности;
* наличие ORM, админ-панели и механизмов валидации;
* понятие Batteries Included;
* особенности микрофреймворков;
* использование FastAPI возможностей современного Python;
* type hints, async/await и asyncio;
* автоматическая генерация документации API;
* рекомендации по выбору фреймворка для различных типов проектов.

## 🔋 Batteries Included

Batteries Included — подход, при котором фреймворк предоставляет большое количество необходимых инструментов непосредственно из коробки.

Ярким примером является Django. Он включает ORM, административную панель, систему маршрутизации, авторизацию, работу с формами и другие компоненты.

Такой подход позволяет быстрее создавать крупные приложения и обеспечивает единую структуру проекта.

В отличие от этого, Flask является микрофреймворком и предоставляет только базовые возможности. Дополнительные компоненты разработчик выбирает самостоятельно.

## ⚡️ FastAPI

Отдельное внимание в проекте уделено FastAPI и его возможностям.

Фреймворк использует современные возможности Python:

* Type Hints — аннотации типов;
* async/await — асинхронное программирование;
* Pydantic — валидация и описание данных;
* OpenAPI — автоматическое описание API;
* автоматическую генерацию интерактивной документации.

Например:

@app.get("/users/{user_id}")
async def get_user(user_id: int):
    return {"user_id": user_id}

На основании аннотации user_id: int FastAPI может определить тип параметра, выполнить его валидацию и использовать эту информацию при формировании документации API.

## 🏆 Рекомендации

### 🚀 Стартап

Django

Подходит для быстрого создания полноценного продукта благодаря большому количеству готовых компонентов: ORM, авторизации, административной панели и другим возможностям.

### ⚡️ Высоконагруженный API

FastAPI

Подходит для API и микросервисов, где важны высокая производительность, асинхронность и большое количество параллельных запросов.

### 🏢 Корпоративный портал

Django

Удобен для крупных корпоративных систем благодаря готовой архитектуре, ORM, административной панели, системе авторизации и большому набору встроенных возможностей.

### 🔧 Небольшой сервис

Flask

Хороший вариант, когда требуется минималистичное решение с высокой степенью контроля над используемыми компонентами.
